# eLearning College — UI & Teacher Portal Upgrade

This package includes the requested login redesign, unified logo, Teacher Portal upload workflow, Admin redesign, and 3-slot Featured Courses system.

## 1. Database upgrade

For an existing database, run:

`database_teacher_featured_upgrade.sql`

It adds:
- `courses.featured` — controls Homepage Featured Courses.
- `teachers.category_id` — assigns one teaching skill/category to a teacher.
- teacher category index + foreign key.

The updated `database.sql` already contains these fields for fresh installations.

## 2. Teacher permissions

Teachers can:
- See their own uploaded lessons in **My Lessons**.
- Upload Video files or Video URLs.
- Upload PDF files or PDF URLs.
- Upload only to courses in the skill/category assigned by Admin.
- View their published lesson.

Teachers cannot:
- Delete lessons.
- Delete uploaded Video/PDF files.
- Manage courses/categories/users.
- Edit or remove media after upload.

Admin remains responsible for deleting/editing content.

## 3. Admin teacher setup

Go to:

`Admin → Teachers`

When creating/editing a teacher, select **Teaching Skill / Category**. The Teacher Portal then shows only courses belonging to that category.

## 4. Featured Courses

Admin can mark a course as **Homepage Featured**.

Rules:
- Maximum 3 active Featured Courses.
- Homepage shows only 3 Featured Course cards.
- `View Featured Courses` opens the full Featured Courses list.

## 5. Login

The new login uses the visual language of the supplied reference:
- Large learning scene on desktop.
- Unified eLearning College logo.
- Blue / white / orange palette.
- Email or Phone + Password.
- Responsive mobile layout.

## 6. Important PHP upload limits

For large teacher video uploads, make sure PHP allows the required size, for example:

- `upload_max_filesize = 500M`
- `post_max_size = 520M`
- suitable `max_execution_time`
- suitable `max_input_time`

Restart Apache/XAMPP after changing PHP settings.
