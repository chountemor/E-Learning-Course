# Admin CSS Structure

Use `assets/css/admin/` to edit Admin styles by section:

- `common.css` — variables, sidebar, topbar, base layout
- `components.css` — cards, buttons, tables, shared components
- `courses.css` — course management pages
- `dashboard.css` — dashboard
- `users.css` — user management
- `forms.css` — admin forms
- `diplomas.css` — diploma section
- `responsive.css` — mobile/tablet responsive rules

`assets/css/admin.css` is only the entry point and imports these files.
